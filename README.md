# Nova Universal Portfolio Template

## Run
Node.js 18+ recommended.

```bash
npm install
npm run dev
```

Open the Vite URL, usually http://localhost:5173/

## Build
```bash
npm run build
npm run preview
```

## Includes
Responsive UI, dark/light theme, mobile menu, smooth navigation, animated hero, scrolling marquee, project filters, project modal, service cards, local contact form validation and responsive layouts.

Replace sample text, links and project data in `src/main.jsx`. The contact form is demo/local only until connected to a form service or backend.
